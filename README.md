# IA UTN-FRSF — landing en un solo archivo

El sitio completo está contenido en `index.html`.

Las clases funcionan como vistas parciales dentro del mismo documento. JavaScript muestra u oculta cada sección y actualiza el hash de la URL (`#clase1`, `#clase2`, etc.) sin recargar la página.

No requiere archivos CSS ni JS externos.
